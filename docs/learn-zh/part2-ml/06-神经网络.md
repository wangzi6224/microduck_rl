## 6.1 一个神经元：算总价，再过一道门

回忆第 2 章：一家店有一张价格表 $\mathbf{w}$，购物清单 $\mathbf{x}$ 的总价是点积 $\mathbf{w}\cdot\mathbf{x}$，再加固定运费 $b$：

$$z = \mathbf{w}\cdot\mathbf{x} + b$$

**神经元**（neuron）就是这家店，再多做一步：把 $z$ 送过一道"门"，门的规则是一个简单函数，叫**激活函数**（activation function）。

最常见的两道门：

| z | ReLU(z) | ELU(z) |
|---|---|---|
| −3 | 0 | −0.950 |
| −1 | 0 | −0.632 |
| −0.5 | 0 | −0.393 |
| 0 | 0 | 0 |
| 0.5 | 0.5 | 0.5 |
| 1 | 1 | 1 |
| 3 | 3 | 3 |

- **ReLU**："负数一律砍成 0，正数原样过。" 最简单。
- **ELU**："正数原样过；负数不砍死，平滑地压到 −1 以上。" 项目用的是它。负半边是 $e^z - 1$——第 1 章的 exp 又来了。

所以一个神经元 = 点积 + 加运费 + 过门：$h = \text{ELU}(\mathbf{w}\cdot\mathbf{x} + b)$。

（叫"神经元"是历史原因：早期研究者用它模仿脑细胞"输入够强才放电"。你不需要在意这个比喻，它就是上面那一行公式。）

## 6.2 为什么要那道门

不过门行不行？实验第 2 节试了：两张价格表串起来（先过 $W_1$ 再过 $W_2$），不夹门：

```
W2 @ (W1 @ x) = [0.2014 0.5602]
(W2 @ W1) @ x = [0.2014 0.5602]   ← 同一个 2×3 的矩阵就能替代
```

**两层不夹门，等于一层**——串多少层都白串，因为"矩阵乘矩阵"还是一个矩阵。
就像连续缩放两次照片，等于缩放一次。

夹了 ELU 就不一样了：

```
W2 @ ELU(W1 @ x) = [-0.3974  0.5737]   ← 合并不了
```

门是"弯"的（负半边是曲线），非线性层叠加能表达更复杂的函数，但有限网络的表示能力和训练结果都有边界。没有门，网络只会画直线；有了门，它能画 sin、能画猫、能画"看到这 61 个数该输出哪 14 个数"。

## 6.3 把神经元排成层，把层叠起来

一家店是一个神经元。512 家店排成一排，就是**一层**（layer）——第 2 章说过，这就是一张 512×61 的价格表：

$$\mathbf{h}_1 = \text{ELU}(W_1\mathbf{x} + \mathbf{b}_1) \qquad (61 \to 512)$$

ELU 对 512 个数**逐个**过门。

把这 512 个输出当成新的"购物清单"，再喂给下一层 256 家店：

$$\mathbf{h}_2 = \text{ELU}(W_2\mathbf{h}_1 + \mathbf{b}_2) \qquad (512 \to 256)$$

再来一层 128 家店，最后一层 14 家店给出 14 个关节的目标（最后一层**不过门**，以免额外限制动作均值的值域）：

```
观测 x (61)
   │  W₁ (512×61) + b₁, ELU
   ▼
 h₁ (512)          ← 隐藏层 1
   │  W₂ (256×512) + b₂, ELU
   ▼
 h₂ (256)          ← 隐藏层 2
   │  W₃ (128×256) + b₃, ELU
   ▼
 h₃ (128)          ← 隐藏层 3
   │  W₄ (14×128) + b₄    （不过门）
   ▼
输出 μ (14)         ← 14 个关节的动作均值（第 4 章）
```

中间三层叫**隐藏层**（hidden layer）——"隐藏"只是说它们既不是输入也不是输出，外面看不到。
这种"一层接一层、每层全连到下一层"的网络叫**多层感知机**（MLP，multi-layer perceptron）。项目的 actor 和 critic 都是 MLP。

实验第 3 节打印了 rsl_rl 建出来的真实网络：

```
MLP(
  (0): Linear(in_features=61, out_features=512, bias=True)
  (1): ELU(alpha=1.0)
  (2): Linear(in_features=512, out_features=256, bias=True)
  (3): ELU(alpha=1.0)
  (4): Linear(in_features=256, out_features=128, bias=True)
  (5): ELU(alpha=1.0)
  (6): Linear(in_features=128, out_features=14, bias=True)
)
```

`Linear` 就是"价格表 + 运费"（$W\mathbf{x}+\mathbf{b}$），`ELU` 就是门。7 个模块，对应上面的图。

## 6.4 数一数旋钮

每层的旋钮 = 价格表格子数 + 运费数：

| 层 | 价格表 W | 运费 b | 旋钮数 |
|---|---|---|---|
| 61 → 512 | 512×61 = 31,232 | 512 | 31,744 |
| 512 → 256 | 256×512 = 131,072 | 256 | 131,328 |
| 256 → 128 | 128×256 = 32,768 | 128 | 32,896 |
| 128 → 14 | 14×128 = 1,792 | 14 | 1,806 |
| **合计** | | | **197,774** |

加上第 4 章那 14 个 σ，actor 共 **197,788** 个旋钮。ELU 没有旋钮（它是固定的函数）。

这就是第 3 章反复提到的那个数字的来历。全部旋钮排成一串就是 $\theta$。

> **停一下，自测**：如果把第一层改成 61 → 256，旋钮少多少？
> <details><summary>答案</summary>第一层变成 256×61+256 = 15,872；第二层变成 256×256+256 = 65,792。总共省下 (31,744−15,872)+(131,328−65,792) = 81,408 个。</details>

## 6.5 它就是一个函数：手写四层

网络不神秘，实验第 4 节用 numpy 手写了它的全部计算：

```python
h = elu(W1 @ obs + b1)    # 61 → 512
h = elu(W2 @ h + b2)      # 512 → 256
h = elu(W3 @ h + b3)      # 256 → 128
out = W4 @ h + b4         # 128 → 14，不过门
```

四行。把 rsl_rl 网络里的 W、b 拷出来，喂同一个 61 维观测：

```
torch 前 5 个输出: [ 0.0828 -0.2874  0.1017  0.0403 -0.0097]
numpy 前 5 个输出: [ 0.0828 -0.2874  0.1017  0.0403 -0.0097]
  ✓ 手写前向 = rsl_rl MLP
```

逐位相同。**"策略网络"= 这四行。** 从输入算到输出的过程叫**前向传播**（forward pass）——下一章的"反向传播"就是它倒过来。

第 1 章说过策略是一个函数；现在它有了具体形状：$\mathbb{R}^{61} \to \mathbb{R}^{14}$，由 4 次矩阵乘和 3 次 ELU 组成，
行为完全由 197,774 个旋钮决定。实验第 5 节喂三个不同观测，得到三个不同输出。

## 6.6 第二个网络：critic

项目里其实有**两个** MLP：

| | 输入 | 隐藏层 | 输出 | 干什么 |
|---|---|---|---|---|
| **actor**（演员） | 61 维观测 | 512, 256, 128 | 14 个动作均值 | 决定怎么动。导出到真机的就是它 |
| **critic**（评论家） | 76 维（多了 15 项只有仿真才知道的"作弊"信息） | 512, 256, 128 | **1 个数** | 估计"当前处境以后大概能得多少分"，只在训练时用 |

critic 为什么需要、为什么可以作弊，第 10 章讲。现在只要知道：**它和 actor 结构一样，只是最后一层输出 1 个数而不是 14 个。**

## 6.7 从两个输入开始，亲手经过一层网络

61 个输入太多，不妨先只给两个教学数：$x=(0.2,-0.1)$。
这里不把它们冒充完整机器人观测，只用来练习计算。
第一层设两个神经元：

$$W=\begin{pmatrix}2&-1\\-3&1\end{pmatrix},\qquad b=(0.1,0).$$

第一行算 $2(0.2)+(-1)(-0.1)+0.1=0.6$；
第二行算 $(-3)(0.2)+1(-0.1)+0=-0.7$。
于是激活前 $z=(0.6,-0.7)$。

ELU 的参数取 1，完整规则是：

$$\operatorname{ELU}(z)=
\begin{cases}z,&z\ge0,\\e^z-1,&z<0.\end{cases}$$

大括号表示“分情况”，不是让两行相加。第一个数非负，原样输出 0.6；
第二个数负，输出 $e^{-0.7}-1\approx-0.503415$。
下一层再把这两个数按 `[1,−2]` 加权，偏置为 0：

$$\mu=1(0.6)+(-2)(-0.503415)=1.606829.$$

到这里完成了一次前向计算。**还没有学习，也没有随机采样。**
权重固定时，同样输入会给同样均值。训练阶段还要按第 4 章的方法从均值附近抽动作，
执行后积累数据，再通过第 7 章的反向传播改权重。

### 隐藏层里的数代表什么

这里第一个隐藏数混合了两个输入，第二个也混合了两个输入。
它们不再分别叫“角速度”和“关节角”，通常也不对应某个指定物理量。
隐藏层是网络学出来的中间表达；不能把 512 个隐藏单元理解成机器人有 512 个传感器。

同理，训练数据有 4096 行，不代表网络有 4096 份参数。
所有环境共用一份 W、b，分别算输出，再把各自经历汇总来训练同一个策略。
这也是为什么不同环境的经验可以帮助同一个机器人控制器。

### 没有激活函数时，偏置也救不了多层结构

两层写全是：

$$y=W_2(W_1x+b_1)+b_2
=(W_2W_1)x+(W_2b_1+b_2).$$

括号里仍然只是一张新的权重表和一份新的偏置。
无论叠多少层，最终还是一个仿射函数。激活函数让中间表达随输入发生非线性变化，
才有能力表达更复杂的条件关系。
但“有表达能力”不保证训练一定找到合适参数，也不保证有限网络能精确表示任意函数。

最后一层用线性输出，是为了不额外把动作均值限制在某个激活函数的值域里。
它并不表示动作可忽视执行器的物理限制；从动作到实际关节运动还有第 17 章的整条执行链。

**自测**：输入维数从 61 增到 62，第一层仍为 512，增加多少网络参数？

**解释**：增加一列权重，共 512 个。偏置个数仍为 512，后续层不变。
但部署输入契约也变了，不能因为“只多一列”就随意改 Microduck 的 61 维约定。

## 本章小结

- **神经元** = 点积 + 运费 + 过门；**激活函数**是那道门，项目用 **ELU**。
- 不夹门，多层等于一层；门引入非线性，让网络能够表达更复杂的关系。
- **层** = 一排神经元 = 一张价格表；**MLP** = 层叠层。actor 是 61→512→256→128→14，最后一层不过门。
- 旋钮数：**197,774** + 14 个 σ = 197,788。
- 网络就是四行 numpy；从输入算到输出叫**前向传播**。
- **critic** 结构相同，输出 1 个数，只训练用。
