## 5.1 学习 = 从例子里找规律

小孩怎么学会认猫？不是背定义，是看几十只猫、被告知"这是猫"，然后见到没见过的猫也认得出。

机器"学习"是同一件事，只是例子换成了数字：给一堆 (x, y) 的例子，让它找出 x 和 y 之间的规律，
然后对没见过的 x 也能说出 y。

第 3 章你已经做过：50 个点，找出了 $y \approx 2x + 1$。这就是学习。

## 5.2 四个零件

任何一次"学习"都由四个零件组成。用第 3 章的例子对照：

| 零件 | 是什么 | 第 3 章里 | 机器人里 |
|---|---|---|---|
| **数据** | 一堆例子 | 50 个 (x, y) 点 | 4096 只机器人跑出来的"看到什么、做了什么、得几分" |
| **模型** | 一台带旋钮的机器（函数），旋钮拧到不同位置行为不同 | $\hat y = wx + b$，2 个旋钮 | 神经网络，197,788 个旋钮 |
| **损失** | 一个打分：现在的旋钮位置"有多差"，越小越好 | MSE：预测和真值差的平方的平均 | PPO 的目标（第 13 章） |
| **优化** | 拧旋钮让损失变小的方法 | 梯度下降 | Adam + 梯度下降（第 7 章） |

**训练** = 反复执行“用数据算损失 → 算梯度 → 拧旋钮”。是否停止，还要结合验证表现与训练预算；PPO 的数据和目标不断变化，不能只以损失停止下降为准。

这四个零件是全书的骨架。后面每一章都在把其中某个零件换成更复杂的版本：第 6 章换模型（神经网络），
第 7 章换优化器（Adam），第 11–13 章换损失（策略梯度、PPO），第 9 章换数据的来源（自己跑出来的）。

> **停一下，自测**："旋钮"在数学里叫什么？
> <details><summary>答案</summary>参数，记作 θ。第 3 章 3.4 节。</details>

## 5.3 用 torch 走一遍

第 3 章手写了两行梯度 `dw = mean(2*err*X)`、`db = mean(2*err)`。旋钮多了以后这不可能手写——
并不意味着每个参数必须写一行；矩阵求导可以合并表达。但随着计算图复杂，手工维护所有导数容易出错。torch 的核心本领就是**自动算梯度**。

实验 `ch05_linear_regression.py` 把第 3 章的例子用 torch 重做。关键的几行：

```python
w = torch.zeros(1, requires_grad=True)   # 声明旋钮。requires_grad=True：“我要它的导数”
b = torch.zeros(1, requires_grad=True)

for it in range(201):
    pred = w * X + b                      # 模型：用现在的旋钮算预测
    L = torch.mean((pred - Y) ** 2)       # 损失：MSE
    L.backward()                          # ★ 自动算 ∂L/∂w、∂L/∂b，存进 w.grad、b.grad
    with torch.no_grad():                 # 拧旋钮时暂停“记账”
        w -= 0.1 * w.grad                 # θ ← θ − α∇L
        b -= 0.1 * b.grad
    w.grad.zero_(); b.grad.zero_()        # 清零，不然下次会累加
```

`L.backward()` 做的事，就是第 1 章的链式法则从外往里乘一遍（第 7 章拆开看）。结果和手写一模一样：

```
                             w        b
---------------------  -------  -------
       torch autograd  2.02617  1.00192
numpy 手写梯度(第3章)  2.02617  1.00192
```

**你不需要现在就会写 torch。** 只要认得这四个动作：声明旋钮（`requires_grad`）、算损失、`backward()`、用 `.grad` 拧旋钮。
后面所有训练代码都是这四步的变体。

## 5.4 泛化：背题 vs 学会

模型只见过 50 个带噪声的点。它在**没见过**的 x 上准吗？实验第 5 节：

```
新的 x  真值 2x+1    模型预测
------  ---------  ----------
    -1         -1    -1.02425
  -0.5          0  -0.0111676
     0          1     1.00192
   0.5          2       2.015
     1          3     3.02808
```

准。这叫**泛化**（generalization）：学到的是规律，不是把 50 个点背下来。

反面叫**过拟合**（overfitting）：模型旋钮太多、数据太少，它把噪声也"学"进去了——训练数据上损失很低，新数据上一塌糊涂。
好比学生把题库答案背下来，换个数字就不会。

<details>
<summary>怎么发现过拟合（可跳过）</summary>
把数据分成两份：训练集（拿来拧旋钮）和测试集（只拿来打分，从不拿来拧）。
训练集损失一直降、测试集损失反而升——过拟合了。
RL 里这个问题形式不同：数据是自己跑出来的，无穷无尽，"过拟合"表现为策略只会仿真里的那一套、到真机就失效（第 17 章的域随机化就是对策）。
</details>

## 5.5 三种"学"的方式

上面的例子里，每个 x 都配了**标准答案** y。这叫**监督学习**（supervised learning）——像有老师批改。
不是所有学习都有标准答案：

| 方式 | 有没有标准答案 | 数据从哪来 | 例子 |
|---|---|---|---|
| **监督学习** | 有：每个输入配一个正确输出 | 人标好的 | 认猫、找直线、翻译 |
| **无监督学习** | 没有：只有输入，自己找结构 | 现成的 | 把顾客分群、压缩图片 |
| **强化学习** | **没有正确动作，只有分数** | **自己跑出来的** | 下棋、打游戏、**机器人走路** |

机器人的难处在最后一行：**没人知道"正确的 14 个关节角"是什么**。你只能让它试，摔了扣分、走对了加分。
而且它看到的数据取决于它自己怎么走——走得歪，看到的全是歪的画面。
这两个特点（只有分数、数据自己造）让强化学习的"损失"零件比 MSE 复杂得多——那是第 3 部的全部内容。

但骨架不变：还是数据、模型、损失、优化四个零件，还是"算损失 → backward → 拧旋钮"的循环。

## 5.6 手算一次“学习”，看参数到底学了什么

假设数据只有两条：$(x,y)=(1,3),(2,5)$。
模型是 $\hat y=wx+b$，开始时 $w=1,b=0$。
这里 $\hat y$ 上面的小帽子读“预测值”，用来区别已经记录下来的目标 y。

| x | 已知目标 y | 当前预测 wx+b | 误差 e=预测−目标 | 误差平方 |
|---:|---:|---:|---:|---:|
| 1 | 3 | 1 | −2 | 4 |
| 2 | 5 | 2 | −3 | 9 |

平均平方误差 MSE 的三个字各对应一个操作：**先作差，再平方，最后平均**。
本例 $L=(4+9)/2=6.5$。如果只平均带符号误差，一高一低可能相互抵消；
如果不除以样本数，同样的数据复制一遍就让损失翻倍，批大小改变也会改变梯度尺度。

现在推导 w 的梯度，不直接报答案。对一条数据：

$$\frac{\partial e^2}{\partial w}
=\frac{\partial e^2}{\partial e}\frac{\partial e}{\partial w}
=2e\,x.$$

第一段是“误差改变，平方损失如何改变”；第二段是“w 改变，预测误差如何改变”。
因为 $e=wx+b-y$，固定 x、b、y 后，w 的倍数就是 x。
对 b 同理得到 $2e$。再把两条数据的贡献平均：

$$\frac{\partial L}{\partial w}
=\frac{2(-2)(1)+2(-3)(2)}2=-8,$$

$$\frac{\partial L}{\partial b}
=\frac{2(-2)+2(-3)}2=-5.$$

用学习率 0.1 **同时用旧参数处的梯度**更新：

$$w_{\text{新}}=1-0.1(-8)=1.8,\qquad b_{\text{新}}=0-0.1(-5)=0.5.$$

新预测是 2.3、4.1；新误差是 −0.7、−0.9；新损失是 $(0.49+0.81)/2=0.65$。
我们没有把答案 3 和 5 存进一个查表程序，而是修改了两个会影响所有输入的参数。
以后输入 1.5 时，同一条规则也能计算预测值。这就是这个例子里“学”的具体含义。

### 已知数据、参数、超参数要分开

- x 和 y 是这次训练给定的数据，不在 `optimizer.step()` 里修改。
- w 和 b 是参数，通过损失梯度更新。
- 学习率 0.1 是超参数：人给优化过程的设置，本例不对它求梯度。

机器人同理：观测和已执行动作是收集来的记录，网络权重才是 PPO 要更新的参数。
下一轮记录会因策略变化而不同，但不是优化器回头改写了历史。

### 损失下降为什么仍要留一份没训练过的数据

设训练数据来自 $y=2x+1$ 加测量噪声。一条曲线可以穿过每一个带噪点，训练损失为零，
却在两点之间剧烈振荡。它记住了这次噪声，未必学到真实关系。
验证集用于选择设置，最终测试集用于评估；若反复根据测试集改模型，它就不再是独立的最终考试。

RL 也会过拟合特定地形、命令范围和随机种子；仿真到真机的差异还包括模型失配，
不能把所有 sim2real 失败都简单归为“数据不够”。

**自测**：本例第一步参数已变成 1.8、0.5，下次能继续直接用 −8、−5 更新吗？

**解释**：不能。误差已经变了，要重新前向计算、重新求梯度。训练循环重复的是计算过程，不是反复加同一个数。

## 📍 映射到项目

> 只需看一眼。

**训练的主循环**在 `rsl_rl/runners/on_policy_runner.py` 的 `learn()` 里，简化后就是四个零件：

```python
for it in range(num_learning_iterations):
    for _ in range(num_steps_per_env):                       # ① 数据：让 4096 只机器人各走 24 步
        actions = self.alg.act(obs)                          #    模型（actor）给动作
        obs, rewards, dones, extras = self.env.step(actions) #    仿真走一步，拿到新观测和分数
        self.alg.process_env_step(obs, rewards, dones, extras)   # 存进缓冲区
    self.alg.compute_returns(obs)                            # ② 把分数整理成“每一步值多少”（第 12 章）
    loss_dict = self.alg.update()                            # ③ 损失 + ④ 优化：PPO 损失，backward，拧旋钮（第 13 章）
```

数据是**自己跑出来的**（第 ① 步），这是它和 5.3 节最大的不同。`update()` 里面那几行你在第 3 章 📍 里见过：
`zero_grad → backward → clip → step`。

## 本章小结

- **学习 = 从例子找规律**，四个零件：**数据、模型（带旋钮的函数）、损失（有多差）、优化（拧旋钮）**。
- **训练** = 循环"算损失 → `backward()` → 拧旋钮"。torch 自动算梯度，四个动作：`requires_grad`、算损失、`backward()`、`.grad`。
- **泛化**：在没见过的数据上也准；**过拟合**：背下了噪声。
- 三种学法：监督（有答案）、无监督（找结构）、**强化（只有分数、数据自己造）**——机器人是最后一种。
