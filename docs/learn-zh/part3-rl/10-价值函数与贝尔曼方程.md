# 第 10 章 · 价值函数与贝尔曼方程

> **上一章我们有了什么**：智能体、环境、奖励、回合、回报 $G_t$、折扣 γ，目标是让平均回报最大。
>
> **这一章要补什么**：回报要等一局结束才知道。可训练时每 24 步就要更新一次（第 7 章），一局有 1000 步——
> 等不起。得有个办法**在中途就估计"现在这个处境以后大概能拿多少分"**。这个估计叫**价值**，估它的网络叫 critic。
> 有了它，还能算出"某个动作比平均好多少"——这就是第 11 章策略梯度真正要用的量。
>
> **本章新词**：价值函数 V、动作价值 Q、优势 A、贝尔曼方程、TD 误差。
> **需要的前提**：第 9 章的回报和期望。

## 10.1 这个格子值多少：价值函数

走廊里，格子 3 离终点一步，格子 0 离四步。直觉上 3 "更值钱"。怎么量化？

**从这个格子出发，按当前策略走下去，平均能拿多少回报。** 这叫**状态价值函数**（state value function）：

$$V^\pi(s) = \mathbb{E}\big[G_t \mid s_t = s\big]$$

读作："在策略 π 下，状态 s 的价值，等于从 s 出发的回报的期望。" 上标 π 提醒你：**价值取决于策略**——乱走的人在格子 3 也不值钱。

最笨的算法：从每个格子出发跑很多局，回报取平均（第 4 章的蒙特卡洛）。实验 `ch10_td_learning.py` 第 1 节，
策略是"70% 向右、30% 向左"，γ=0.9，每个格子跑 3000 局：

```
V_MC = [0.138 0.265 0.452 0.758 0.   ]
```

越靠近终点越值钱；终点本身是 0（到了就结束，之后没分）。

## 10.2 贝尔曼方程：价值可以递归地算

蒙特卡洛要跑完整局。有没有不用跑完的办法？

看回报的递推（第 9 章 9.4 节）：$G_t = r_t + \gamma G_{t+1}$。两边取期望：

$$V^\pi(s) = \mathbb{E}\big[\,r_t + \gamma\, V^\pi(s_{t+1})\,\big]$$

读作："s 的价值 = 这一步的奖励 + γ × 下一个状态的价值，取平均。" 这就是**贝尔曼方程**（Bellman equation）。

它把"一整局的总分"变成了"这一步的分 + 下一格的价值"——**只看一步**。就像问"从北京到上海多远"可以答"到天津的距离 + 天津到上海的距离"。

实验第 2 节把走廊的转移概率写成表，解出精确的 V，然后验证格子 1：

```
格子 1：V(1) = 0.2548，贝尔曼右边 = 0.2548
```

左边等于右边。蒙特卡洛的估计也对上了（误差 < 0.01）。

<details>
<summary>展开写的贝尔曼方程（可跳过）</summary>

把"取平均"里的随机性写全——动作按策略抽、下一状态按转移概率抽：

$$V^\pi(s) = \sum_a \pi(a\mid s)\sum_{s'} P(s'\mid s,a)\big[R(s,a,s') + \gamma V^\pi(s')\big]$$

5 个格子就是 5 个未知数、5 个方程的线性方程组，实验用 `np.linalg.solve` 直接解了。机器人的状态是连续的、无穷多个，解不了方程组，只能靠下面的 TD 学习和神经网络去逼近。
</details>

## 10.3 TD 学习：走一步，修一点

贝尔曼方程给了一个**不用等结束**的学习办法：每走一步，拿 $r_t + \gamma V(s_{t+1})$ 当"更靠谱的估计"，
把 $V(s_t)$ 往它挪一点：

$$\delta_t = r_t + \gamma V(s_{t+1}) - V(s_t) \qquad\qquad V(s_t) \leftarrow V(s_t) + \alpha\,\delta_t$$

| 符号 | 怎么读 | 就是 |
|---|---|---|
| $r_t + \gamma V(s_{t+1})$ | | "目标"：这一步的真实奖励 + 下一格的**估计**价值 |
| $\delta_t$ | "德尔塔 t" | **TD 误差**（temporal-difference error）：目标 − 现在的估计。正 = 比想的好，负 = 比想的差 |
| $\alpha$ | | 学习率，往目标挪的比例 |

实验第 3 节从全 0 开始，一步一修：

```
回合数    V(0)    V(1)   V(2)   V(3)
------  ------  ------  -----  -----
     0  -0.003  -0.005  -0.01  0.045
    10  -0.047  -0.044  0.025  0.422
   100   0.077   0.188  0.391  0.794
  1000   0.165   0.271  0.465  0.761
  3999   0.131   0.227  0.504  0.756
精确值      [0.14  0.255 0.46  0.758]
```

4000 局后逼近精确值。注意 V(3) 最先学准（它旁边就是终点，目标里的 $V(s')$ 是 0，不用估）；V(0) 最慢（它的目标里全是别的格子的估计）。

**自举**（bootstrapping）：目标里用了自己的估计 $V(s_{t+1})$。这是 TD 的优点（不用等结束）也是它的代价（早期估计不准，目标就不准）。第 12 章的 λ 就是在"信自己多少"上做折中。

> **停一下，自测**：某一步 δ > 0，说明什么？
> <details><summary>答案</summary>这一步过后的处境比原来估计的好（拿到的奖励 + 下一格的价值 超出了预期）。第 11 章会看到：δ > 0 的动作该多做。</details>

## 10.4 动作价值与优势：这个动作比平均好多少

V(s) 是"在 s 按策略随便走的平均"。再细一点——**在 s 先做某个动作 a，之后再按策略走**，平均能拿多少？
这叫**动作价值函数**（action value function）$Q^\pi(s, a)$。

有了 Q，就能问最关键的问题：**在 s 做 a，比"在 s 按策略随便做"好多少？**

$$A^\pi(s, a) = Q^\pi(s, a) - V^\pi(s)$$

这叫**优势**（advantage）。实验第 4 节在格子 2：

```
动作    Q(2,a)  A(2,a) = Q − V
----  --------  --------------
向左  0.269954       -0.190385
向右  0.541933       0.0815937
V(2) = π-加权的 Q = 0.4603
```

向右优势为正（比平均好），向左为负（比平均差）。两条性质：
- $V(s) = \sum_a \pi(a|s)\,Q(s,a)$——V 是 Q 按策略的加权平均。
- 优势按策略加权平均恰好为 0——"平均动作的优势是 0"。

**优势是第 11 章的主角**：策略梯度要做的就是"把优势为正的动作的概率推高、为负的推低"。

## 10.5 critic：用一个网络学 V

走廊有 5 个格子，V 是一张 5 项的表。机器人的状态是连续的、无穷多个，表存不下——用一个神经网络代替：
输入观测，输出一个数，这就是第 6 章 6.6 节提到的 **critic**。

训练它的办法就是 10.3 节的 TD：目标 $r_t + \gamma V(s_{t+1})$（第 12 章会用更好的目标），损失是 MSE——**critic 的训练是监督学习**，第 5 章那一套。

**为什么 critic 可以"作弊"**：它输入 76 维，比 actor 多 15 项只有仿真器才知道的信息（真实前进速度、脚的接触力、真实的无噪声关节角……）。
这不违规，因为 **critic 只在训练时用来估价值，部署到真机的是 actor**。信息越多估得越准，actor 学得越快。
这叫**非对称 actor-critic**，第 15 章列出那 15 项。

## 📍 映射到项目

> 只需看一眼。

**critic 的形状**（`microduck_velocity_env_cfg.py`）和 actor 一样是 `(512, 256, 128)` ELU，输出 1 个数（`MLPModel(..., "critic", 1, ...)`）。

**每一步都问 critic 一次**，`rsl_rl/algorithms/ppo.py` 的 `act()`：

```python
self.transition.actions = self.actor(obs, stochastic_output=True).detach()   # actor 抽动作
self.transition.values = self.critic(obs).detach()                            # critic 估 V(s_t)，存起来
```

**TD 误差**在 `compute_returns()` 里，注释都写好了：

```python
# TD error: r_t + gamma * V(s_{t+1}) - V(s_t)
delta = st.rewards[step] + next_is_not_terminal * self.gamma * next_values - st.values[step]
```

`next_is_not_terminal`：回合终止时（摔倒）下一格价值当 0——第 9 章说的"之后没分了"。第 12 章逐行读这个函数。

## 本章小结

- **价值** $V^\pi(s)$：从 s 出发按策略走的平均回报。终点价值 0。
- **贝尔曼方程** $V(s) = \mathbb{E}[r + \gamma V(s')]$：一整局的分 = 这一步 + 下一格的价值。
- **TD 学习**：目标 $r + \gamma V(s')$，**TD 误差** δ = 目标 − 估计，$V \leftarrow V + \alpha\delta$。不用等结束，代价是**自举**。
- **Q** 是先做某动作再按策略走的价值；**优势** $A = Q - V$ = 比平均好多少，按策略加权平均为 0。
- **critic** = 用网络学 V，监督学习；训练时可以看仿真器的"作弊"信息。

**下一章**：有了"哪个动作比平均好"，就该把它的概率推高了。可是策略输出的是概率分布，动作是抽出来的，
"抽样"这一步怎么求导？答案是一个小技巧，它是整个策略梯度的心脏——[第 11 章 · 策略梯度](11-策略梯度.md)。
