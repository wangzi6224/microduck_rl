# 第 4 章 · 概率与期望

> **上一章我们有了什么**：梯度下降的完整循环。损失是"50 个点取平均"。
>
> **这一章要补什么**：训练里到处是随机。每回合机器人出生的姿势是随机的，电池电压是随机抽的，
> 传感器读数带随机噪声，连策略吐出的动作都**故意**加了随机——不然它永远不会试新动作。
> 于是"平均"要升级成**期望**，而且只能靠"多抽几次取平均"来估；"策略"也不再是"吐 14 个数"，
> 而是"吐一个 14 维的**概率分布**，动作从里面抽"。
>
> **本章新词**：期望、方差、高斯分布、log 概率、熵。
> **需要的前提**：第 1 章的 exp、第 2 章的向量、第 3 章的"取平均"。

## 4.1 随机的东西，怎么说清楚

掷骰子，你不知道会出几，但你知道"每个数各 1/6 的可能"。
"结果不确定、但每种结果的可能性确定"的东西，叫**随机变量**，习惯用大写字母 $X$。
"每种结果各多大可能"叫它的**分布**。

骰子：结果 1 到 6，每个概率 $p(x) = 1/6$。所有概率加起来必须是 1（总得掷出一个）。

### 连续的情况：抽电压

项目里给每只机器人配的"电池电压"，是从 6.5 V 到 8.2 V 之间**随机抽一个**，每个值机会均等。
这叫**均匀分布**，记作 $U(6.5, 8.2)$（U 是 uniform，"均匀"）。

连续的量有个小别扭：抽到"恰好 7.000000 V"的概率是 0——可能的值有无穷多个。
所以改问"落在某一段里的概率"：$U(6.5, 8.2)$ 一共 1.7 V 宽，落在 7.0 到 7.5 这半伏里的概率是 0.5/1.7 = 29%。

代码里 `torch.rand(...)` 或 `uniform_(6.5, 8.2)` 就是"从均匀分布抽一个数"。

## 4.2 期望：抽很多次的平均

骰子掷无穷多次，平均是多少？每个数各占 1/6：

$$\frac{1+2+3+4+5+6}{6} = 3.5$$

这个"按概率加权的平均"叫**期望**（expectation），记作 $\mathbb{E}[X]$，读"X 的期望"。

$$\mathbb{E}[X] = \sum_x x\,p(x)$$

（Σ 又是 for 循环：每个可能的结果 × 它的概率，累加。）

注意 3.5 根本不是骰子能掷出的数。期望是"平均"，不是"最可能出现的"。

均匀分布 $U(a, b)$ 的期望就是区间中点 $(a+b)/2$：电压的期望是 7.35 V。

**一条后面反复用的性质**：期望是"线性"的——
"X 的两倍加 3"的期望 = "X 的期望"的两倍加 3；"X + Y"的期望 = X 的期望 + Y 的期望。
用符号：$\mathbb{E}[aX + b] = a\,\mathbb{E}[X] + b$，$\mathbb{E}[X+Y] = \mathbb{E}[X] + \mathbb{E}[Y]$。
（第 11 章证明"给奖励减个基准不影响学习方向"就靠它。）

### 方差：散得多开

两个班平均分都是 70。一个班全是 70 分，另一个班一半 40 一半 100。平均一样，"散的程度"完全不同。

**方差**（variance）量的就是这个：每个结果离期望多远，取平方，再按概率平均。

$$\mathrm{Var}[X] = \sum_x (x - \mu)^2\,p(x)\qquad(\mu \text{ 就是 } \mathbb{E}[X])$$

方差开根号叫**标准差**，记 $\sigma$（"西格玛"）——单位和 X 一样，所以更直观。

骰子：方差 2.92，标准差 1.71。全班 70 分：方差 0。

**σ 又出现了。** 第 1 章钟形打分里的 σ 叫"宽容度"，这里叫"标准差"，它们都控制宽度，但**不是数值相同的统计量**；两条公式的分母差一个 2，详见 4.10 节。
4.4 节你会看到为什么。

## 4.3 不知道概率怎么办？多抽几次

期望的定义要用到"每个结果的概率"。可是训练时我们**不知道**概率——不知道机器人下一步会看到什么、
会得几分。只能让它跑起来看。

好消息：**抽很多次，取算术平均，结果会逼近期望。** 这叫**大数定律**。

实验第 2 节从 $U(6.5, 8.2)$ 抽电压，抽 1 个、10 个……10 万个，看平均值：

```
 样本数 n     样本均值        与期望的差
------  -------  -----------
     1  7.58283     0.232835
    10  7.46628     0.116279
   100   7.4267    0.0766978
  1000  7.36161    0.0116138
 10000  7.34658  -0.00342421
100000  7.34889  -0.00111279
理论期望 7.35
```

抽 1 个差 0.23，抽 10 万个差 0.001。在独立同分布且方差有限的条件下，**样本数涨 100 倍，样本均值的标准误缩 10 倍**，不是每次实测误差都严格缩 10 倍。

**样本平均让无法直接计算的期望变得可以估计。** PPO 会对 4096 × 24 = 98,304 条记录中的相应量取平均。
但同一机器人的连续帧存在相关性，不能保证误差按独立样本公式缩到 1/313；4.9 节会把这个区别算清楚。
"用样本平均估期望"有个名字：**蒙特卡洛估计**。

## 4.4 高斯分布：第 1 章的钟形，这次是概率

身高、考试分数、传感器噪声……很多随机量的分布长一个样：中间高、两边低、对称，像一口钟。
这叫**高斯分布**，也叫**正态分布**。

![高斯分布](../figures/ch04_gaussian_68_95.png)

它由两个数完全决定：钟的中心 μ（期望）和钟的宽度 σ（标准差）。记作 $\mathcal{N}(\mu, \sigma^2)$
（花体 N；括号里第二个是 σ²，方差，不是 σ——容易记错）。

钟的高度公式：

$$p(x) = \frac{1}{\sigma\sqrt{2\pi}}\,\exp\!\left(-\frac{(x-\mu)^2}{2\sigma^2}\right)$$

先看右半边：$\exp(-\frac{(x-\mu)^2}{2\sigma^2})$——**这就是第 1 章的钟形打分**，"偏差"换成了 $x - \mu$，分母多了个 2。
形状一模一样：x 在 μ 处最高，离得越远越低，σ 越大钟越宽。
左半边 $\frac{1}{\sigma\sqrt{2\pi}}$ 只是个常数，让整口钟的面积恰好是 1（概率总和为 1）。
打分不需要面积为 1，所以第 1 章没这一项。

| 符号 | 就是 |
|---|---|
| $\mu$ | 钟的中心 |
| $\sigma$ | 钟的宽度 |
| $(x-\mu)^2$ | 离中心多远的平方 |
| $\pi$ | 这里是圆周率 3.14159。**不是**策略 π。第 13 章两个 π 会同时出现，靠上下文分 |

μ=0、σ=1 时叫**标准正态**。实验第 3 节手算这条公式，和 torch 的现成函数对比：

```
  x  p(x) 手写  p(x) torch
---  ---------  ----------
 -2   0.053991    0.053991
 -1   0.241971    0.241971
  0   0.398942    0.398942
  1   0.241971    0.241971
  2   0.053991    0.053991
```

上图的阴影：落在 μ±1σ 内的概率 68%，±2σ 内 95%。记这两个数就够用。

### 从高斯分布抽一个数

抽标准正态很容易（`torch.randn`）。想抽 $\mathcal{N}(\mu, \sigma^2)$ 呢？**先抽一个标准正态 ε，再算 μ + σε。**

```python
eps = torch.randn(14)          # 14 个标准正态噪声
action = mean + std * eps      # 变成均值 mean、宽度 std 的高斯样本
```

反过来，$(x - \mu)/\sigma$ 把任何高斯变量变回标准正态——第 8 章"输入归一化"用的就是这一招。

## 4.5 策略：吐一口钟，从钟里抽动作

现在可以把"策略"说准确了。

第 0 章说"网络吐 14 个数当动作"。更准确的说法：**网络吐 14 个均值 μ；每个关节各有一个宽度 σ；
动作 = 从这 14 口钟里各抽一个数。**

$$\text{动作}_i = \mu_i(\text{观测}) + \sigma_i\,\varepsilon_i$$

- μ 依赖观测（网络算出来的）："我认为该做的"。
- σ **不**依赖观测，是 14 个独立的旋钮，初值 1.0，训练中会变。
- ε 是每步新抽的标准正态噪声："顺便试试旁边的"。

这就是**探索**：不加噪声，机器人永远只做"现在认为最好的"，永远发现不了更好的。

写成概率的语言：$\pi(a \mid s)$，读"在观测 s 下选动作 a 的概率"。竖线读"**给定**"——分布随观测而变，观测不同，钟的中心不同。
下标 θ（$\pi_\theta$）提醒你这口钟由网络参数决定。

实验第 4 节真的抽了一次：

```
mean[:4]   = [ 0.4623 -0.0880 -0.6536  0.1705]    ← 网络给的均值（前 4 个关节）
eps[:4]    = [-1.0712  0.1227 -0.5663  0.3731]    ← 抽到的噪声
action[:4] = [-0.6089  0.0347 -1.2200  0.5436]    ← mean + 1.0 × eps
```

**部署到真机时不加噪声**，直接用 μ（第 19 章）。

### log 概率：14 个概率怎么合成一个

后面 PPO 要问："刚才抽到的这个 14 维动作，在当前这口钟下，概率有多大？"

给定观测，本项目用各维条件独立的高斯，所以联合密度 = 14 个一维密度**相乘**。
密度不一定小于 1；许多很小的密度相乘可能下溢。比如 $0.4^{14}≈0.0000027$ 本身仍能存下，
但更极端的尾部密度乘积就危险了。更稳妥的办法是直接算 **log 密度**，然后相加。

第 1 章提过 exp 的逆运算叫 $\ln$（自然对数），它有一条性质：**乘法变加法**——
$\ln(a \times b) = \ln a + \ln b$。所以

$$\log \pi(\mathbf{a}\mid\mathbf{s}) = \sum_{i=1}^{14} \log p_i(a_i)$$

14 个 log 相加，数值不会下溢，求导也好算。实验：

```
                log π(a|s)
--------------  ----------
手写 Σ log p_i    -19.0465
torch .sum(-1)    -19.0465
```

−19 对应联合密度 $e^{-19} \approx 5\times10^{-9}$。这是本例的密度值，不是单点概率，也不表示所有 14 维密度都很小。
PPO 只用两个 log π 的**差**（第 13 章），绝对值不重要。

（机器学习文献里的 log 默认就是 ln。）

## 4.6 熵：这口钟有多"随机"

宽的钟（σ 大）抽出来的数天南海北，窄的钟（σ 小）几乎总抽到 μ 附近。
"一个分布有多随机"叫**熵**（entropy）。对高斯分布它只和 σ 有关：σ 越大熵越大。

实验第 4 节：

```
  σ     一维熵
---  ---------
0.1  -0.883647
0.5   0.725791
  1    1.41894
  2    2.11209
```

（连续分布的熵可以是负数，这没问题，只看相对大小。14 个关节的熵相加。）

**用处**：训练时给熵一点奖励（`entropy_coef=0.01`），阻止 σ 过早缩到 0——σ 变 0 就不探索了，卡在当前解上。
wandb 里 `Mean noise std` 就是 14 个 σ 的平均，缓慢下降是健康的（越来越确定），骤降到 0 是过早收敛的信号。

<details>
<summary>进阶：熵和 log 密度的公式（可跳过）</summary>

熵的定义：$H = -\mathbb{E}[\log p(x)]$——"平均意外程度"（概率越小的结果越"意外"，$-\log p$ 越大）。
高斯分布的熵有闭式解 $H = \frac12\log(2\pi e\,\sigma^2)$，上表就是它。

一维高斯的 log 密度：$\log p(x) = -\frac{(x-\mu)^2}{2\sigma^2} - \log\sigma - \frac12\log 2\pi$。
第一项是"离均值多远"，后两项在 σ 固定时是常数。
</details>

## 4.7 密度不是概率：为什么钟的高度可以超过 1

把连续分布想成一张沿街铺开的“可能性地图”。横轴是位置，纵轴是每单位长度分到多少可能性。
真正的概率是某段区间下方的**面积**，不是某一点的高度。

例如 $X\sim U(0,0.2)$。全部概率 1 均匀铺在宽度 0.2 上，密度是：

$$p(x)=1/0.2=5.$$

密度等于 5 并不违反概率不超过 1，因为宽度 0.01 的小段概率是 $5\times0.01=0.05$。
整段概率仍是 $5\times0.2=1$。一个无限窄的单点面积是 0。
高斯也是同样道理，只是高度随位置变化，宽度有限的区间要累加小条面积。

对于 $\mu=0,\sigma=0.1$，高斯中心密度约为 3.989，大于 1。
它的 log 密度也可以为正。因此代码 `Normal.log_prob(a)` 里的 `prob`，在连续动作下实际给的是 **log 密度**。
名字容易让人误解，计算本身没有问题。

PPO 比较同一个动作在新旧分布下的密度比；若取足够小的相同区间，区间宽度约掉，
这个比率也描述该动作附近的概率如何改变。第 13 章会用到它。

## 4.8 对数为什么能把乘法变成加法

先从你认识的乘方来理解：$e^2e^3=e^{2+3}=e^5$。
自然对数 $\ln$ 做的是“把指数找回来”：$\ln(e^2)=2$。
所以对正数 a、b，若 $a=e^u,b=e^v$，则：

$$\ln(ab)=\ln(e^{u+v})=u+v=\ln a+\ln b.$$

同理，$\ln(a/b)=\ln a-\ln b$。这不是近似，而是恒等式。
计算机可以存两份 log 密度，先相减，再用 exp 还原比率。

也补齐第 11 章需要的一条导数。令 $y=\ln x$，等价于 $x=e^y$。
两边对 x 求导，链式法则给出 $1=e^y y'=xy'$，于是 $y'=1/x$（$x>0$）。
以后见到 $\nabla\log\pi=(\nabla\pi)/\pi$，就是这一条和链式法则。

## 4.9 方差为什么要平方，样本越多又能解决什么

假设两个结果等概率为 1 和 3。均值是 2，偏差是 −1 和 +1。
如果直接平均偏差，结果是 0，好像一点都不分散。
平方后再平均得到方差 1，开根号得到标准差 1，才能表达分散程度。

如果收集 n 个相互独立、同分布、方差有限的样本，样本均值的方差是：

$$\operatorname{Var}(\bar X)=\frac{\sigma_X^2}{n},\qquad
\operatorname{std}(\bar X)=\frac{\sigma_X}{\sqrt n}.$$

$\sigma_X$ 描述单个结果的散布；$\sigma_X/\sqrt n$ 描述“多次重新做整个抽样实验时，平均值有多不稳定”。
后者叫标准误，**不是这一次平均值与真值的确切距离**。某次抽样增加了样本，误差仍可能暂时变大。

机器人连续两帧很像，所以 24 步不是 24 个完全独立的样本。
并行环境能增加经历的多样性，但不能简单把 98,304 条记录当成 98,304 次独立掷骰子，
再保证误差缩小到 1/313。更多样本也不能修复评分规则写错造成的系统性偏差。

## 4.10 三个 σ，先问它在描述什么

| 出现位置 | 谁决定它 | 它变大意味着什么 |
|---|---|---|
| 高斯奖励核的宽度 | 人在 cfg 中设 | 同样的误差少扣一些分，敏感区域外移 |
| 动作高斯的标准差 | 可训练参数 | 在均值周围探索得更分散 |
| 观测归一化的标准差 | 采样统计得到 | 这一列历史输入的波动更大 |

三者可以都写 `std`，却不是同一份数。调奖励的 std 不会直接修改动作噪声。

奖励核 $e^{-x^2/s^2}$ 与正态密度 $C e^{-x^2/(2\sigma^2)}$ 外形相似，
但要指数相同，必须满足 $s=\sqrt2\sigma$。奖励的 s 不能直接套用“±1σ 包含 68%”的概率结论；
奖励既没有要求面积为 1，也未必描述任何随机变量。

**自测**：连续策略在某动作处密度为 2，是否意味着这个动作有 200% 的概率？

**解释**：不是。概率要算一段区域的面积；密度还依赖动作单位。PPO 用相同坐标和单位下的新旧密度比。

**造钟、抽样、算 log 概率、算熵**，同一个文件：

```python
self._distribution = Normal(mean, std)             # 用网络给的 mean 和 14 个 std 造 14 口钟
return self._distribution.sample()                 # 抽：mean + std × 噪声
return self._distribution.log_prob(a).sum(dim=-1)  # 14 个 log 概率相加（4.5 节）
return self._distribution.entropy().sum(dim=-1)    # 14 个熵相加（4.6 节）
```

**均匀分布抽命令**，`src/mjlab_microduck/tasks/mdp.py` 的 `UniformPoseCommand`：

```python
for i, (lo, hi) in enumerate(self.cfg.ranges):
    self._command[env_ids, i] = r.uniform_(lo, hi)       # 每一维从 U(lo, hi) 抽
if self.cfg.zero_command_prob > 0.0:
    zero_mask = torch.rand(n) < self.cfg.zero_command_prob
    self._command[env_ids[zero_mask]] = 0.0             # 以某个概率强制命令 = 全零
```

最后两行有意思：4.1 节说连续分布抽到**恰好** 0 的概率是 0，可"命令全零 = 原地站着"是真机最常见的状态。
不专门给它一个概率，策略永远练不到它。仓库 `AGENTS.md` 里 "Zero-command behavior must be explicitly trained" 说的就是这件事。

## 本章小结

- **随机变量**有**分布**：骰子每面 1/6；均匀分布 $U(a,b)$ 区间内机会均等。
- **期望** $\mathbb{E}[X]$ = 按概率加权的平均；**方差**/**标准差 σ** = 散得多开。
- **大数定律**：多抽取平均 → 逼近期望，误差 ∝ $1/\sqrt n$。代码里每个 `.mean()` 都在估一个期望。
- **高斯分布** $\mathcal{N}(\mu,\sigma^2)$：第 1 章的钟形，μ 是中心、σ 是宽度；抽样 = μ + σ×标准正态。
- **策略** $\pi_\theta(a\mid s)$：网络吐 14 个 μ，14 个 σ 是独立旋钮，动作从钟里抽——这就是探索。
- **log 概率**：14 个概率相乘 → 14 个 log 相加。**熵**：σ 越大越随机。

**数学地基到此打完。** 你手里有了：函数与导数、链式法则、向量与矩阵、梯度与梯度下降、期望与抽样、高斯与 log π。
